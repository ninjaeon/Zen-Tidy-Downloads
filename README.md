**Rename your downloads with ease, and do it in style!**

## Features
* AI renaming
* Undo button if when you don't like the name

## Install via Sine

1. Open Sine settings.
2. Enable "Enable installing JS from unofficial sources." in Sine settings.
3. Add a mod by repository and enter the GitHub repo URL or path:
   - https://github.com/ninjaeon/Zen-Tidy-Downloads/tree/all-api
4. Click Install.  Configure mod settings for API keys and other preferences.

Note: When the official repository is updated, you may need to manually reinstall the mod using the official repository's install method to receive updates.
Note: After installing, you may need to clear Firefox's startup cache (visit about:support and click "Clear startup cache"), then restart the browser.
