# Zen-Tidy-Downloads

![image](https://raw.githubusercontent.com/ninjaeon/Zen-Tidy-Downloads/all-api/image.png)

**Rename your downloads with ease, and do it in style!**

## Features
* AI renaming
* Undo button if when you don't like the name

## Install via Sine

1. Open Sine settings.
2. Enable "Enable installing JS from unofficial sources." in Sine settings.
3. Add a mod by repository and enter the GitHub repo URL or path:
   - https://github.com/ninjaeon/Zen-Tidy-Downloads
4. Enable the mod. Sine will fetch `theme.json`, CSS, preferences, and scripts automatically.

That's all, your just downloading a file. _What did you expect?_
